# practice-Capstone1

A small static **HTML-only** resume/portfolio practice project from a web-development capstone exercise.

## Repository scope

The current site consists of:

- `index.html` — primary resume page and the original capstone requirements preserved as HTML comments.
- `dummy.html` — secondary linked page used by the exercise.
- `assets/` — local images referenced by the pages.

There is no package manager, JavaScript application, CSS framework, build system, automated test suite, or server component in the current repository.

The original capstone specification intentionally restricts the exercise to HTML. Do not introduce CSS/JavaScript/framework tooling unless a later task explicitly changes that learning constraint.

## Run / inspect

Open `index.html` directly in a browser, or serve the repository with any simple static-file server if desired. No install or build step is required.

For validation, inspect the rendered pages and verify links/images/HTML structure manually. Do not claim automated tests or a build pass when none exists.

## Agent guidance

Read `AGENTS.md` and `.agent/STATE.md` before changing the project. Preserve the exercise history and keep any future modernization clearly separated from the original HTML-only capstone scope.
